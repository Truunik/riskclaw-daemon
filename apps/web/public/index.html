preflight DeFi transactions on MegaETH before your wallet broadcasts.

Decode a proposed tx, derive its destination state via CREATE2, read live pool / position data, return ALLOW / WARN / BLOCK in under a second. On 1s EVM blocks, the entire preflight loop fits in the signing path.

// quickstart

three steps. zero hosted infra. your own RPC, your own keys.

git clone https://github.com/Truunik/riskclaw-daemon
cd riskclaw-daemon
bun install

# preflight a real Kumbaya swap on mainnet (chainId 4326)
bun run claw preflight kumbaya 0xbc91070ad1B65B8EBec3a71bF8bA6b212f130Ca3 1e18 0

# score a route via the aggregator skill
MEGAETH_CHAIN_ID=4326 MEGAETH_RPC_URL=https://mainnet.megaeth.com/rpc \
  bun run claw invoke mega-aggregator score '{"amountIn":"1000000","hops":[{"address":"0x…","protocol":"prism","fromToken":"0x…","toToken":"0x…"}]}'

add a protocol decoder

  scorePool: async (pool, chainId, ctx) => {
    // read live pool state via ctx.chain.readContract({...})
    // return { protocol, poolAddress, riskBps, reasons, components }
  },
};

register in skills/mega-aggregator/src/index.ts · const DECODERS = [KumbayaDecoder, PrismDecoder, YourDecoder];
