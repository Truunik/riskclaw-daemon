// surfaces

preflight — full calldata-aware. Recognizes router02 / universalRouter / quoter / posMgr / factory targets; decodes exactInputSingle + exactOutputSingle; pulls tokens from on-chain when not in calldata; runs simulation with revert classification.

aggregator-score — pool-only. Reads slot0, liquidity, balanceOf at latest-300. Returns PoolRisk { riskBps, reasons, components }.
