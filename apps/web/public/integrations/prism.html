prism · UniV3-style DEX on MegaETH (custom-fee variants)

Prism (prismfi.cc) is a UniV3-style AMM with custom-fee routing (SelectiveTaxRouter), part of the broader Prism product suite (Swap / Pools / Predict / Earn-via-Beefy). surface: live · UniversalRouter recognized · pool scoring

// what's caught

same UniV3 read surface as Kumbaya — all signals work identically against Prism pools.

  • UniversalRouter target recognition — preflight identifies a tx as a Prism swap when its to field hits the canonical UniversalRouter
  • Pool liquidity depth + reentrancy state via slot0 + liquidity
  • V3 oracle observation cardinality
  • TVL drift via balanceOf at latest-300 blocks (~5 min)
  • Sim-revert classification — softer signal when the target is a recognized Prism contract

// surfaces

aggregator-score — fully wired. Score any Prism pool via mega-aggregator.score. Try it on the live widget with pool 0xC2FaC0B5B6C075819E654bcFbBBCda2838609d32 (healthy: cardinality 2 000, active liquidity).

preflight — live · router-recognized. Sending a Prism UniversalRouter tx through mega-preflight.check returns a protocol: { name: 'prism', recognized: 'router' } partial verdict + simulation result + scoring of any pools you reference. Full UniversalRouter calldata decoding is on backlog (same gap as Kumbaya UniversalRouter — uses a command-stream encoding that needs its own parser).

// try it · pool scoring (simple case)

curl -X POST http://localhost:4242/api/score \
  -H 'content-type: application/json' \
  -d '{"protocol":"prism","chainId":4326,"pool":"0xC2FaC0B5B6C075819E654bcFbBBCda2838609d32","amountIn":"1000000"}'

# returns ALLOW/0 for the healthy pool above. swap in 0x1B6C…70E1 to see WARN/5500
# (zero liquidity + cardinality=1) or any *b1d-token pool to see token-pattern flags.

// try it · raw preflight (Prism UniversalRouter tx)

For a real Prism swap, send the user's calldata + to directly:

curl -X POST http://localhost:4242/api/preflight-raw \
  -H 'content-type: application/json' \
  -d '{
    "to": "0x955d56F6391a496231509134e0d2Beadf82a223f",
    "data": "0x3593564c…",
    "chainId": 4326
  }'

Returns the verdict with protocol.name === "prism" + simulation outcome.

// open items

  • UniversalRouter command-stream decoding — the highest-impact next step. Each command (V3_SWAP_EXACT_IN, V3_SWAP_EXACT_OUT, PERMIT2_PERMIT, WRAP_ETH, UNWRAP_WETH, SWEEP) has its own encoding. Lands as a shared univ3-universal-router module benefiting both Kumbaya and Prism.
  • SwapRouter02 + QuoterV2 + SelectiveTaxRouter — Prism docs name them; addresses still not published and not visible in tx.to traces from sampled swaps. If you have authoritative addresses, drop a PR or open an issue.
  • Multi-hop path decoding (same gap as Kumbaya — single-pool variants only today).
